# Student Record Management System

A simple C-based Student Record Management System using structures and file handling.

## Features

- Add Student
- Display All Students
- Search Student
- Update Student
- Delete Student
- Exit

## Technologies Used

- C Programming
- Structures
- File Handling
- Functions
- CRUD Operations

## Data Stored

- Roll Number
- Name
- Age
- Course
- Marks

## How to Run

Compile the program:

gcc student.c -o student

Run:

student

## Project Purpose

This project demonstrates the use of C programming, structures, functions, file handling, and basic data management operations.
